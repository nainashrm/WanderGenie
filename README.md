# 🌍 WanderGenie — AI-Powered Travel Planner

An intelligent full-stack travel planning application that generates personalized trip itineraries, weather-aware packing suggestions, and smart travel recommendations using AI.

---

# ✨ Features

- 🤖 AI-generated travel itineraries
- 🧳 Smart packing list generation
- 🌤️ Weather forecast integration
- 💰 Budget-based trip planning
- 📅 Day-wise itinerary scheduling
- 🎯 Interest-based recommendations
- 🌙 Modern responsive UI
- ⚡ Fast full-stack architecture
- 🔐 User Authentication System
- 📄 Export itinerary as PDF
- ❤️ Save & manage trips
- 🧠 AI-powered smart recommendations

---

# 🖥️ Tech Stack

## Frontend
- Next.js
- React
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- REST APIs

## AI & Services
- Groq API
- AI itinerary generation
- Intelligent fallback mock system

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/nainashrm/WanderGenie.git
```

---

## Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

---

## Backend Setup

```bash
cd backend
npm install
npm run dev
```

---

# 🔑 Environment Variables

Create `.env` files.

## Frontend

```env
NEXT_PUBLIC_API_URL=http://localhost:5000
```

## Backend

```env
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret
GROQ_API_KEY=your_groq_key
```
